# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and Semantic Versioning.

## [0.2.0] - 2026-09-27

### Added

- Publishable `@glaucodutra/pyrealtime-client` browser SDK with declarations, ESM, and CommonJS builds.
- Text-only WebRTC connection mode that does not request microphone permission.
- Public runtime `updateSession()` method for supported Realtime session changes.
- Tag-driven GitHub release and optional npm trusted-publishing workflow.

### Changed

- The repository now contains both reusable client protocol code and a separately built reference UI.
- MIT license and Node/dependency/compatibility policy are explicit.

## [0.1.0] - 2026-09-23

- Initial reference frontend.
